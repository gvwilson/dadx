A Forecasting Pipeline

Build a pipeline that forecasts a numeric time series (river level for the disaster example, or population counts for the ecology example) by fitting a simple trend and seasonal model, and judge it by forecasting the held-out recent past. A distinct kind of analysis: prediction over time.

  • A forecast is an extrapolation, and its error grows with the horizon.
  • Naive and seasonal baselines give a floor to beat.
  • Backtesting holds out the recent past to judge a model.
  • Forecast uncertainty matters as much as the point forecast.

10.1 A synthetic river series

  • We need a series whose shape we control, so we generate one: a slow rising trend plus a yearly cycle plus random noise.
  • The disaster example forecasts river_level from the readings series; the ecology example forecasts population count from the environment series, and the same code runs with the column renamed.
  • Pin the seed first so the series is reproducible.
import math
import random
import altair as alt
import polars as pl
SEED = 20261108
random.seed(SEED)
  • A monthly reading over six years gives 72 points.
  • The level is a base height plus a trend that rises a little each month, a sine wave that repeats every 12 months, and Gaussian noise.
  • The sine wave is the season: winter highs and summer lows, or any repeating yearly pattern.
N_YEARS = 6
PERIOD = 12                 # months per year
BASE = 3.0                  # metres
SLOPE = 0.02                # metres per month
AMPLITUDE = 0.8             # metres
PHASE = math.pi / 6
NOISE = 0.15                # metres
def make_river_levels(n):
    rows = []
    for t in range(n):
        seasonal = AMPLITUDE * math.sin(2 * math.pi * t / PERIOD + PHASE)
        noise = random.gauss(0.0, NOISE)
        rows.append({"t": t, "level": BASE + SLOPE * t + seasonal + noise})
    return rows
df = pl.DataFrame(make_river_levels(N_YEARS * PERIOD))
print(df.head())
  • t is the month index; the level is everything else.

10.2 Hold out the recent past

  • Backtesting means pretending the last stretch of the series has not happened yet: we fit only on the earlier points and forecast the rest.
  • The held-out points are the recent past, and they are the honest test: the model never sees them while it is being fit.
  • We hold out the final year.
HOLDOUT = 12
train = df.slice(0, len(df) - HOLDOUT)
test = df.slice(len(df) - HOLDOUT, HOLDOUT)
print(f"train: {len(train)} points, test: {len(test)} points")

10.3 A naive baseline

  • The simplest forecast repeats the last known value for every future point.
  • It is nearly always wrong, but it gives a floor: a real model should beat it, or the model is not earning its keep.
def naive_forecast(train, horizon):
    last_value = train["level"][-1]
    return [last_value] * horizon
naive_pred = naive_forecast(train, HOLDOUT)
print(naive_pred[:4])

10.4 A trend and seasonal model

  • A slightly smarter model fits a straight line through the series to capture the trend.
  • The slope is the average change per month, estimated by least squares; the intercept is where that line starts.
def fit_trend(t, y):
    t_mean = sum(t) / len(t)
    y_mean = sum(y) / len(y)
    num = sum((ti - t_mean) * (yi - y_mean) for ti, yi in zip(t, y))
    den = sum((ti - t_mean) ** 2 for ti in t)
    slope = num / den
    intercept = y_mean - slope * t_mean
    return intercept, slope
  • After removing the trend, what is left is the seasonal shape plus noise.
  • Average the detrended leftovers by month: month 0 gets the mean of every January leftover, month 1 the mean of every February, and so on.
  • Those twelve averages are the additive seasonal terms.
  • The spread of the residuals around the fitted pattern, sigma, is our first estimate of the typical error.
def fit_trend_seasonal(t, y, period):
    intercept, slope = fit_trend(t, y)
    detrended = [yi - (intercept + slope * ti) for ti, yi in zip(t, y)]
    by_month = {m: [] for m in range(period)}
    for ti, d in zip(t, detrended):
        by_month[ti % period].append(d)
    seasonal = {m: sum(v) / len(v) for m, v in by_month.items()}
    fitted = [intercept + slope * ti + seasonal[ti % period] for ti in t]
    residuals = [yi - fi for yi, fi in zip(y, fitted)]
    sigma = (sum(r * r for r in residuals) / len(residuals)) ** 0.5
    return intercept, slope, seasonal, sigma
  • Forecasting is just extending the line: for each month ahead, add the trend times that month plus that month’s seasonal term.
def trend_seasonal_forecast(t, y, horizon, period):
    intercept, slope, seasonal, _ = fit_trend_seasonal(t, y, period)
    last_t = t[-1]
    forecast = []
    for k in range(horizon):
        t_k = last_t + k + 1
        forecast.append(intercept + slope * t_k + seasonal[t_k % period])
    return forecast
t_train = train["t"].to_list()
y_train = train["level"].to_list()
trend_pred = trend_seasonal_forecast(t_train, y_train, HOLDOUT, PERIOD)
print(trend_pred[:4])

10.5 Measure the error

  • Mean absolute error is the average distance between the forecast and the truth, in the units of the series.
  • We compute it on the held-out points, which the fit never saw.
def mean_absolute_error(y_true, y_pred):
    return sum(abs(a - b) for a, b in zip(y_true, y_pred)) / len(y_true)
y_test = test["level"].to_list()
naive_mae = mean_absolute_error(y_test, naive_pred)
trend_mae = mean_absolute_error(y_test, trend_pred)
print(f"naive MAE:          {naive_mae:.3f} m")
print(f"trend+seasonal MAE: {trend_mae:.3f} m")
  • The trend and seasonal model should beat the naive baseline, because it captures the yearly rise and fall that the naive forecast ignores.
  • Beating the naive floor is the minimum bar; it does not mean the forecast is good.

10.6 Plot actual vs forecast

  • Altair draws the actual held-out points and both forecasts on the same axes.
  • The closer a forecast line sits to the actual line, the smaller its error.
plot_df = pl.DataFrame({
    "t": test["t"].to_list() * 3,
    "level": y_test + naive_pred + trend_pred,
    "series": ["actual"] * HOLDOUT + ["naive"] * HOLDOUT + ["trend+seasonal"] * HOLDOUT,
})
chart = alt.Chart(plot_df).mark_line().encode(
    x=alt.X("t:Q", title="month"),
    y=alt.Y("level:Q", title="river level (m)"),
    color=alt.Color("series:N", title=None),
)
chart.save("forecast.json")
  • The naive line is flat, so it misses the seasonal curve entirely.
  • The trend+seasonal line bends with the season, so it tracks the actual values much more closely.

10.7 Forecast uncertainty

  • A point forecast is a single number; a useful forecast also says how sure we are.
  • sigma from the training fit is a first estimate of the typical error.
  • A rough interval is the forecast plus or minus two sigma: about 95% of values should land inside if the errors are normal and independent.
intercept, slope, seasonal, sigma = fit_trend_seasonal(t_train, y_train, PERIOD)
print(f"residual sigma: {sigma:.3f} m")
print(f"first forecast, +/- 2 sigma: {trend_pred[0]:.3f} m +/- {2 * sigma:.3f} m")

  • The interval widens as we forecast further ahead, because each step adds new uncertainty.

  • For the naive model the error accumulates like a random walk, so its interval grows with the square root of the horizon.

  • A constant band is a simplification; a real pipeline reports a band that widens with the horizon.

  • The ecology twin forecasts population count the same way: generate a trend plus seasonal series, hold out the recent past, fit the naive and trend+seasonal models, and compare their MAE.

  • Rename the column and adjust the units, and the pipeline runs unchanged.
