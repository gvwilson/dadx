A Time-Series Generator

Build a generator that produces a daily time series for either running example: river level for the disaster example, or temperature and pollution for the ecology example. The series is trend plus seasonality plus noise plus one injected anomaly, so the monitoring and forecasting lessons have a known target to find.

  • A time series is trend plus seasonality plus noise.
  • Because we choose the components, we know the true signal before we analyze anything.
  • Injected anomalies give the monitoring lesson a known target to recover.

6.1 The decomposition

  • Import the tools this lesson needs. math and random come from the standard library; polars holds the data and altair draws it.
  • Pin the seed first so the series is identical on every run.
import math
import random
from datetime import date, timedelta
import altair as alt
import polars as pl
SEED = 20261108
random.seed(SEED)
  • A time series decomposes into three parts. The trend is the slow, long-run movement. The seasonality is the repeating cycle. The noise is the random jitter on top.
  • Real data only hands you the sum; a generator lets you set each part and see how they combine.
  • We name the components as constants so the recipe reads like the model it encodes.

6.2 A daily river series

  • A river gauge records one number per timestamp. We synthesize two years of daily readings for the disaster example’s readings table.
N_YEARS = 2
N_DAYS = N_YEARS * 365    # daily readings over two years
PERIOD = 365              # days per year: the seasonal cycle
BASE = 3.0                # metres: typical river level
SLOPE = 0.001             # metres per day: a slow, steady rise
AMPLITUDE = 0.6           # metres: the yearly swing
PHASE = 2.2               # radians: shifts the peak to the calendar
NOISE = 0.12              # metres: day-to-day jitter
FLOOD_DAY = 500           # the day we inject the flood
FLOOD_JUMP = 3.0          # metres: the brief excursion
  • The level at day t is the base plus a linear trend, a sine wave that repeats every 365 days, and Gaussian noise.
  • A flood is a brief excursion: on one chosen day we add a large jump, then the series returns to its usual shape.
  • We tag that day in an anomaly column so later lessons have a labeled target, not just a story.
def make_river_levels(n):
    start = date(2024, 1, 1)
    rows = []
    for t in range(n):
        seasonal = AMPLITUDE * math.sin(2 * math.pi * t / PERIOD + PHASE)
        noise = random.gauss(0.0, NOISE)
        level = BASE + SLOPE * t + seasonal + noise
        flood = t == FLOOD_DAY
        if flood:
            level += FLOOD_JUMP
        rows.append({
            "timestamp": (start + timedelta(days=t)).isoformat(),
            "station_id": 1,
            "river_level": round(level, 3),
            "anomaly": flood,
        })
    return rows
readings = pl.DataFrame(make_river_levels(N_DAYS))
readings.head()
  • The timestamp is a real calendar date, one day apart, so the plot and any date arithmetic behave like real monitoring data.
  • anomaly is the ground truth: it says which point is unusual, so a detector can be scored against it.
  • A real readings row also carries rainfall_mm and wind_speed; we generate only river_level here, and the other columns follow the same recipe.

6.3 Plot the series

  • Draw the series and drop a red mark on the injected flood.
  • The trend and season are the slow rise and the yearly wave; the noise is the fuzz; the flood is the lone spike.
base = alt.Chart(readings).encode(x="timestamp:T")
line = base.mark_line().encode(y="river_level:Q")
marks = base.mark_point(color="red", size=60).encode(
    y="river_level:Q"
).transform_filter("datum.anomaly")
chart = (line + marks).properties(width=600, height=220)
chart.save("river-levels.json")
  • The red dot sits exactly on the injected point, because we put it there.
  • A detector that flags that point is right; one that misses it or flags the noise is wrong, and we can measure which because we know the truth.

6.4 The ecology twin

  • The same recipe maps to the ecology example by renaming the columns and the units.
  • temperature_c carries the seasonal cycle; pollution_ppm is a flatter baseline with its own injected spike.
  • A real environment row keys each reading to a site_id; here we generate one site’s series.
T_BASE = 15.0             # degrees C: mean annual temperature
T_AMPLITUDE = 10.0        # degrees C: summer peak, winter trough
T_NOISE = 1.2             # degrees C: day-to-day jitter
P_BASE = 40.0             # ppm: typical pollution level
P_NOISE = 3.0             # ppm: day-to-day jitter
SPIKE_DAY = 500           # the day we inject the pollution spike
SPIKE_JUMP = 120.0        # ppm: the brief excursion
def make_environment(n):
    start = date(2024, 1, 1)
    rows = []
    for t in range(n):
        seasonal = T_AMPLITUDE * math.sin(2 * math.pi * t / PERIOD + PHASE)
        temperature = T_BASE + seasonal + random.gauss(0.0, T_NOISE)
        pollution = P_BASE + random.gauss(0.0, P_NOISE)
        spike = t == SPIKE_DAY
        if spike:
            pollution += SPIKE_JUMP
        rows.append({
            "date": (start + timedelta(days=t)).isoformat(),
            "site_id": 1,
            "temperature_c": round(temperature, 2),
            "pollution_ppm": round(pollution, 2),
            "anomaly": spike,
        })
    return rows
environment = pl.DataFrame(make_environment(N_DAYS))
environment.head()
  • The temperature series is a seasonal wave around a fixed mean; the pollution series is a flat baseline with a single spike.
  • Plot pollution to see the same injected-anomaly shape in a different unit.
base = alt.Chart(environment).encode(x="date:T")
line = base.mark_line().encode(y="pollution_ppm:Q")
marks = base.mark_point(color="red", size=60).encode(
    y="pollution_ppm:Q"
).transform_filter("datum.anomaly")
chart = (line + marks).properties(width=600, height=220)
chart.save("pollution.json")
  • The spike stands out from the baseline exactly as the flood did, so the monitoring lesson’s target exists in both running examples.
  • Because the seed is pinned, every number above is fixed: run the notebook again and you get the same series, the same spike, and the same plot.
