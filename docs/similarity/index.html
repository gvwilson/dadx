A Similarity Pipeline

Build a pipeline that finds the records most like a given one (e.g., which past incidents resemble the one just reported, or which survey sites or specimens look like a new one) under a distance on chosen features. A distinct kind of analysis: nearest-neighbor and similarity search.

  • “Similar” means close under some distance on chosen features.
  • Feature choice and scaling decide what similarity means.
  • Nearest neighbors generalize from “equal” to “nearby”.
  • Similarity underpins recommendation and record linkage.

13.1 Generate the data

  • Pin the seed first so the pseudo-random stream reproduces exactly.
  • random.seed makes the “random” numbers deterministic: same seed, same rows.
import math
import random
import polars as pl
SEED = 20261108
random.seed(SEED)
  • Each incident has three numeric features: severity, latitude, and longitude.
  • severity runs 1 (minor) to 5 (major); the coordinates sit in south-eastern Australia, matching the running example.
def make_incidents(n):
    rows = []
    for i in range(1, n + 1):
        rows.append({
            "id": i,
            "severity": random.randint(1, 5),
            "latitude": round(random.uniform(-40.0, -30.0), 4),
            "longitude": round(random.uniform(140.0, 150.0), 4),
        })
    return pl.DataFrame(rows)
incidents = make_incidents(12)
print(incidents)
  • id labels a row; it is not a feature, because a label carries no notion of closeness.
  • Text columns would need a different distance, so we leave them out for now.

13.2 Choose a distance

  • A distance turns two feature vectors into one non-negative number.
  • Euclidean distance is the straight-line distance: the square root of the sum of squared differences.
  • math.dist computes it; the distance is zero only when two rows are identical.
def euclidean(a, b):
    return math.dist(a, b)

13.3 Scale the features

  • severity spans 1 to 5, but each coordinate spans about 10 units.
  • In raw distance the wider coordinate spread outweighs severity, so severity barely moves the answer.
  • Standardizing gives every feature the same spread, so each counts equally.
features = ["severity", "latitude", "longitude"]
print("minimums:", incidents.select(features).min().to_dicts()[0])
print("maximums:", incidents.select(features).max().to_dicts()[0])
  • A z-score subtracts the feature’s mean and divides by its standard deviation.
  • After scaling, every feature has mean 0 and standard deviation 1.
  • “One unit apart” now means “one standard deviation apart” in any feature.
def zscore(col):
    return (col - col.mean()) / col.std()
scaled = incidents.with_columns([
    zscore(pl.col(f)).alias(f"{f}_z") for f in features
])
print(scaled.head(3))

13.4 Find the nearest neighbors

  • Take the first incident as the query.
  • Compute its distance to every row; the query’s distance to itself is zero.
  • Drop the query row, sort ascending, and keep the k closest.
zcols = [f"{f}_z" for f in features]
query = scaled.row(0, named=True)
q = tuple(query[c] for c in zcols)
distances = [
    euclidean(q, tuple(row[c] for c in zcols))
    for row in scaled.iter_rows(named=True)
]
scaled = scaled.with_columns(pl.Series("distance", distances))
k = 3
nearest = (
    scaled.filter(pl.col("id") != query["id"])
    .sort("distance")
    .head(k)
)
print(nearest.select(["id", "severity", "latitude", "longitude", "distance"]))
  • Nearest neighbors generalize “equal to” into “near to”.
  • Recommendation (“show me more like this”) and record linkage (“is this the same site?”) both rest on this idea.

13.5 Scaling changes the answer

  • Compare the same query in raw and scaled space to see the choice matter.
q_raw = tuple(query[c] for c in features)
raw_dists = [
    euclidean(q_raw, tuple(row[c] for c in features))
    for row in scaled.iter_rows(named=True)
]
scaled = scaled.with_columns(pl.Series("raw_distance", raw_dists))
raw_nearest = (
    scaled.filter(pl.col("id") != query["id"])
    .sort("raw_distance")
    .head(k)
)
print(raw_nearest.select(["id", "severity", "raw_distance"]))
  • The two lists differ: raw distance ranks id 8 in the top three, scaled distance puts id 7 there instead.
  • Which one you use is a decision about what “similar” means for this problem.
