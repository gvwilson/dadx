An A/B Test Pipeline

Build a pipeline that compares two variants (e.g., two alerting strategies for disaster response, or two sampling protocols for the field survey) with a permutation test and a bootstrap confidence interval for the effect size. A distinct kind of analysis: experimentation and inference.

  • An experiment compares two variants of one thing, holding everything else fixed.
  • Here the question is whether two alerting strategies differ in how fast people respond.
  • Variant A is a siren alert; variant B is a text message.
  • We will simulate response times so the true answer is known, then test whether the pipeline recovers it.
  • A fixed seed makes the random data reproducible.
import random
import statistics
import polars as pl
random.seed(20241108)
  • Each group has 200 responders, with response times drawn from a bell curve.
  • Variant A has a mean of 120 seconds; variant B is a bit faster at 110 seconds.
  • The two curves share a spread of 25 seconds, so the difference is real but not huge.
n = 200
mean_a, mean_b = 120.0, 110.0
sd = 25.0
times_a = [random.gauss(mean_a, sd) for _ in range(n)]
times_b = [random.gauss(mean_b, sd) for _ in range(n)]
print(f"A: {statistics.mean(times_a):.1f}s  B: {statistics.mean(times_b):.1f}s")
  • Put both groups into one Polars dataframe, with a column recording which variant each row came from.
rows = [("A", t) for t in times_a] + [("B", t) for t in times_b]
df = pl.DataFrame(rows, schema=["variant", "response_time"], orient="row")
print(df.group_by("variant").len())
print(df.head(5))
  • The observed effect is the difference in means, A minus B.
  • It is just a number; the rest of the lesson asks whether it is real or could be noise.
observed = statistics.mean(times_a) - statistics.mean(times_b)
print(f"observed A - B = {observed:.1f}s")
  • The null hypothesis says there is no real difference: both groups come from the same distribution.
  • Under the null, any difference we saw is just random assignment of labels.
  • A permutation test simulates the null by shuffling the variant labels many times.
  • Each shuffle recomputes the difference; if the labels do not matter, shuffled differences look like the real one.
all_times = times_a + times_b
num_shuffles = 10_000
extreme = 0
for _ in range(num_shuffles):
    random.shuffle(all_times)
    left = statistics.mean(all_times[:n])
    right = statistics.mean(all_times[n:])
    if abs(left - right) >= abs(observed):
        extreme += 1
p_value = extreme / num_shuffles
print(f"permutation p-value = {p_value:.4f}")

  • The p-value is how often shuffles look at least as extreme as the real data.

  • A small p-value means the real difference is unlikely under the null, so we reject the null.

  • A p-value near 0 here is expected: we built in a true 10 second difference.

  • The permutation test needs no formula for the sampling distribution, which is why it is easy to trust.

  • A p-value says whether a difference exists, not how big it is.

  • The bootstrap estimates the effect size with a confidence interval.

  • Resample each group with replacement, recompute the difference, and repeat to build a distribution of plausible effects.

num_boot = 10_000
boot_diffs = []
for _ in range(num_boot):
    ra = [random.choice(times_a) for _ in range(n)]
    rb = [random.choice(times_b) for _ in range(n)]
    boot_diffs.append(statistics.mean(ra) - statistics.mean(rb))
boot_diffs.sort()
lower = boot_diffs[int(0.025 * num_boot)]
upper = boot_diffs[int(0.975 * num_boot)]
print(f"bootstrap 95% CI for A - B = [{lower:.1f}, {upper:.1f}]s")

  • The middle 95% of bootstrap differences is the confidence interval.

  • The interval here should sit near the true 10 second gap and exclude 0.

  • A confidence interval that excludes 0 agrees with the p-value: the effect is real.

  • The bootstrap works because resampling mimics drawing new samples from the same population.

  • Permutation and bootstrap both trade many recomputations for assumptions we would otherwise have to justify.

  • In a real deployment, swap the simulated times for measured response times and re-run unchanged.

  • The ecology twin is the same shape: two sampling protocols, compared on the counts or masses they produce.

  • Seed everything, log the p-value and interval, and a colleague can reproduce the whole comparison from scratch.
