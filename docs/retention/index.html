A Cohort and Retention Pipeline

  • A cohort shares a defining event; retention tracks its members over time.
  • Grouping activity by cohort and period is a self-join.
  • Retention answers “do they come back?”, not just “how many started?”.
  • For the disaster example the members are volunteers and the activity is an incident response; for the ecology example the members are sites and the activity is a survey.
  • The defining event is a choice. Here it is a volunteer’s first response, not their sign-up month, because signing up is not the same as showing up.
  • Start with two helpers that move between "YYYY-MM" labels and integer month numbers. An integer makes “months since first response” a subtraction.
  • Generate the two tables with a fixed seed so the lesson is reproducible. A volunteer has a joined sign-up month; an incident records one response at a timestamp.
  • joined records when a volunteer signed up and can precede their first response, which is why the cohort is derived from the incident log instead of trusted from joined.
  • Convert each response’s timestamp to an integer month so later arithmetic is a plain column difference.
  • Join each response to its volunteer to carry along the name, role, and sign-up month. Then take each volunteer’s earliest response month: that is their cohort.
  • The cohort assignment is computed from the same records it is then joined back onto, which is why this is a self-join. period is months since a volunteer’s first response: zero means “their first month”.
  • Group by cohort and period and count distinct volunteers active in each cell. Rows are cohorts, columns are periods.
  • Check against a property that must hold: a cohort’s period-0 count equals its size, because every member responded in their first month.
  • Counts answer “how many?”. Dividing each cell by its cohort size answers “what fraction?”, which is a retention rate.
  • Plot the matrix as a heatmap. Reading down a column shows one cohort aging; reading across a row shows the same period for different cohorts.
