A Linear Regression Pipeline

Build a least-squares regression pipeline: fit a line to predict a numeric outcome (e.g., response time from a disaster’s severity and distance, or organism mass from pollution and length) then inspect the residuals, and evaluate the fit on held-out data. A distinct kind of analysis: predictive modeling with a continuous outcome.

  • Least squares minimizes the sum of squared residuals.
  • Coefficients have concrete, checkable meanings.
  • Residuals reveal what the model misses.
  • A fitted line is a claim, not a fact; evaluate it on unseen data.

11.1 The Model

  • Regression predicts a numeric outcome from numeric features.
  • The disaster example predicts an incident’s response time in minutes.
  • Two features drive that response: the incident’s severity and its distance.
  • We assume the relationship is linear: response = w0 + w1*severity + w2*distance.
  • w0 is the intercept; w1 and w2 are slopes, the extra minutes per unit of each feature.
  • The ecology example uses the same shape: mass = w0 + w1*pollution + w2*length.
  • Our job is to estimate the three coefficients from data, not to assume them.

11.2 Generate Synthetic Data

  • We make data with known coefficients so we can check the fit against truth.
  • A fixed seed makes the data reproducible: the same numbers on every run.
  • Each row is one incident: a severity from 1 to 5, a distance in kilometres, and noise.
  • Noise stands for everything the model does not capture, like road conditions.
  • The hidden truth is response = 5 + 3*severity + 0.4*distance + noise.
  • If the fit recovers numbers near 5, 3, and 0.4, we know it works.
import math
import random
import polars as pl
random.seed(1234)
n = 200
intercept = 5.0
slope_severity = 3.0
slope_distance = 0.4
severities = []
distances = []
response_times = []
for _ in range(n):
    severity = random.randint(1, 5)
    distance = random.uniform(0.5, 20.0)
    noise = random.gauss(0.0, 4.0)
    severities.append(severity)
    distances.append(distance)
    response_times.append(intercept + slope_severity * severity + slope_distance * distance + noise)
data = pl.DataFrame({
    "severity": severities,
    "distance_km": distances,
    "response_min": response_times,
})
print(data.head())

11.3 The Normal Equations

  • Least squares chooses the coefficients that minimize the sum of squared residuals.
  • A residual is the gap between an observed value and the value the line predicts.
  • Squaring makes big errors cost more than small ones and removes the sign.
  • For a linear model the best coefficients have a closed form called the normal equations.
  • We solve X'X w = X'y, where X holds a column of ones plus the features.
  • We build X'X and X'y with plain loops, then solve by Gaussian elimination.
  • No NumPy: this is the whole idea, written out where we can see it.
def solve_linear(a, b):
    """Solve a x = b by Gaussian elimination with partial pivoting."""
    n = len(b)
    m = [row[:] + [b[i]] for i, row in enumerate(a)]
    for col in range(n):
        pivot = col
        best = abs(m[col][col])
        for r in range(col + 1, n):
            if abs(m[r][col]) > best:
                best = abs(m[r][col])
                pivot = r
        if best < 1e-12:
            raise ValueError("singular matrix")
        m[col], m[pivot] = m[pivot], m[col]
        for r in range(col + 1, n):
            factor = m[r][col] / m[col][col]
            for c in range(col, n + 1):
                m[r][c] -= factor * m[col][c]
    x = [0.0] * n
    for r in range(n - 1, -1, -1):
        total = m[r][n]
        for c in range(r + 1, n):
            total -= m[r][c] * x[c]
        x[r] = total / m[r][r]
    return x
def fit_least_squares(X, y):
    """Return the coefficients w that minimize the squared residuals."""
    n = len(X)
    p = len(X[0])
    xtx = [[0.0] * p for _ in range(p)]
    xty = [0.0] * p
    for i in range(n):
        row = X[i]
        for j in range(p):
            xty[j] += row[j] * y[i]
            for k in range(p):
                xtx[j][k] += row[j] * row[k]
    return solve_linear(xtx, xty)
def predict(X, w):
    """Return the fitted value for each row: its dot product with w."""
    return [sum(row[j] * w[j] for j in range(len(w))) for row in X]

11.4 Fit and Interpret

  • The design matrix X has one column per coefficient: ones, severity, distance.
  • We fit on all the data to see how close the estimates come to the truth.
  • The intercept is the predicted time for severity 0 and distance 0.
  • The severity slope means one more severity step adds about 3 minutes.
  • The distance slope means one more kilometre adds about 0.4 minutes.
  • These meanings hold only because the relationship really is linear here.
X = [[1.0, float(s), d] for s, d in zip(severities, distances)]
y = list(response_times)
w = fit_least_squares(X, y)
print("coefficients (intercept, severity, distance):")
print(w)

11.5 Look at the Residuals

  • Residuals are the part of the outcome the model did not explain.
  • Their mean is near zero: least squares balances over- and under-prediction.
  • Their spread shows how far off the model typically is.
  • A pattern in residuals, like growing with severity, means the model missed structure.
  • With synthetic noise the residuals should look random, which is the honest case.
y_pred = predict(X, w)
residuals = [y[i] - y_pred[i] for i in range(n)]
print("mean residual:", sum(residuals) / len(residuals))
print("residual range:", min(residuals), "to", max(residuals))

11.6 Evaluate on Held-Out Data

  • A model that fits the data it saw can still fail on new incidents.
  • Fitting error only measures memorization, not prediction.
  • We split the data: fit on a training set, score on a test set the model never saw.
  • The split uses its own seed so the data-generation seed stays fixed.
  • Mean absolute error is the average size of the prediction error, in minutes.
  • Training and test MAE should be close; a big gap is a warning sign.
def mean_absolute_error(y_true, y_pred):
    """Average absolute difference between true and predicted values."""
    return sum(abs(t - p) for t, p in zip(y_true, y_pred)) / len(y_true)
random.seed(99)
idx = list(range(n))
random.shuffle(idx)
split = int(0.8 * n)
X_train = [X[i] for i in idx[:split]]
y_train = [y[i] for i in idx[:split]]
X_test = [X[i] for i in idx[split:]]
y_test = [y[i] for i in idx[split:]]
w_train = fit_least_squares(X_train, y_train)
y_train_pred = predict(X_train, w_train)
y_test_pred = predict(X_test, w_train)
print("training MAE:", mean_absolute_error(y_train, y_train_pred))
print("test MAE:", mean_absolute_error(y_test, y_test_pred))

11.7 Plot Actual vs Predicted

  • A plot shows what a single error number hides.
  • Each point is one held-out incident, actual time on one axis, predicted on the other.
  • Points on the diagonal are perfect predictions.
  • Points above the diagonal were over-predicted; below, under-predicted.
  • A tight cloud around the diagonal means the model explains most of the variation.
  • A cloud that fans out means the error grows in one direction.
import altair as alt
results = pl.DataFrame({
    "actual": y_test,
    "predicted": y_test_pred,
})
lo = min(min(y_test), min(y_test_pred))
hi = max(max(y_test), max(y_test_pred))
diag = pl.DataFrame({"v": [lo, hi]})
reference = alt.Chart(diag).mark_line(color="grey", strokeDash=[4, 4]).encode(
    x="v",
    y="v",
)
points = alt.Chart(results).mark_circle().encode(
    x=alt.X("actual", title="Actual response time (minutes)"),
    y=alt.Y("predicted", title="Predicted response time (minutes)"),
    tooltip=["actual", "predicted"],
)
chart = (reference + points).properties(
    width=400,
    height=400,
    title="Actual vs predicted on held-out incidents",
)
chart.save("regression.json")

11.8 Summary

  • Least squares picks the line that minimizes the sum of squared residuals.
  • The normal equations give that line in closed form, solvable in pure Python.
  • Coefficients read as “extra minutes per severity step” and “per kilometre”.
  • Residuals show what the model missed; a clean model leaves random-looking noise.
  • Never trust a fit on its own training data; score it on held-out incidents.
  • The actual-vs-predicted plot shows the whole story a single error hides.
